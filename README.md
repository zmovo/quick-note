# 碎片记录

Windows 10/11，Python 3.11+，只使用 Python 标准库。双击 `启动碎片记录.pyw` 启动；关闭总览窗口后仍在后台运行。

先在任意应用中选中文字，再按快捷键：

| 快捷键 | 用途 | 文件 |
| --- | --- | --- |
| Alt+1 | 今日学习，供以后复习 | `records/YYYY-MM-DD/今日学习.md` |
| Alt+2 | 待补齐的知识点 | `records/YYYY-MM-DD/待补齐.md` |
| Alt+3 | 打开每日总览 | 不写入文件 |

总览默认展示笔记：左侧选择日期，右侧以两列卡片显示“需要复习”和“待补全”，卡片支持选中文字和一键复制。右上折线图标可展开趋势，旁边的循环箭头可刷新；左下角的 ? 图标会显示快捷键。按 Esc 或点击关闭按钮只会隐藏总览，程序继续在后台运行；按 Alt+3 可再次打开。程序运行期间会注册这三个全局热键，原应用的相同快捷键将被占用。保存时会自动发送 Ctrl+C；如果当前应用不允许复制所选文字，会显示失败提示，也不会写入旧剪贴板内容。

旧版记录已迁入对应日期目录，原文件备份在 `backup/legacy/`。双击启动文件时需要 `.pyw` 与 `pythonw.exe` 的文件关联；如未关联，可在项目目录运行 `pythonw 启动碎片记录.pyw`。
