# 碎片记录

Windows 10/11，Python 3.11+，只使用 Python 标准库。双击 `启动碎片记录.pyw` 启动；总览会在默认浏览器打开。关闭浏览器标签页后，热键服务仍在后台运行。

先在任意应用中选中文字，再按快捷键：

| 快捷键 | 用途 | 文件 |
| --- | --- | --- |
| Alt+1 | 今日学习，供以后复习 | `records/YYYY-MM-DD/今日学习.md` |
| Alt+2 | 待补齐的知识点 | `records/YYYY-MM-DD/待补齐.md` |
| Alt+3 | 打开每日总览 | 不写入文件 |

总览使用 HTML、CSS 和 JavaScript 构建，由 Python 在本机提供数据。左侧选择日期和分类，右侧以两列卡片显示“待复习”和“待补全”。点击顶部“添加卡片”可直接输入知识卡片，选择记录类型与分类，保存到当前选中日期。现有记录已归入 Java。左侧可新增、删除分类；删除分类时，其记录归入“未分类”。分类下拉框可筛选记录；选定分类后，Alt+1/Alt+2 的新记录会写入该分类，选择“全部分类”时新记录写入“未分类”。点击卡片的“改分类”可调整记录分类；卡片支持选中文字、复制和删除。右上角可查看趋势或刷新记录。按 Alt+3 可再次打开总览。程序运行期间会注册这三个全局热键，原应用的相同快捷键将被占用。保存时会自动发送 Ctrl+C；如果当前应用不允许复制所选文字，会显示失败提示，也不会写入旧剪贴板内容。

旧版记录已迁入对应日期目录，原文件备份在 `backup/legacy/`。双击启动文件时需要 `.pyw` 与 `pythonw.exe` 的文件关联；如未关联，可在项目目录运行 `pythonw 启动碎片记录.pyw`。

总览支持 Markdown 图片：`![图片说明](assets/example.png)`，相对路径以记录所在日期目录为基准，也支持 HTTPS/HTTP 图片链接。本地图片须位于 `records/` 内，支持 PNG、JPEG、GIF、WebP、BMP。新增或编辑卡片时，可在内容框中按 Ctrl+V 粘贴剪贴板里的 PNG 或 BMP 图片，图片会保存到该卡片日期的 `assets/` 目录并插入正文。截图后（如 Win+Shift+S），也可直接按 Alt+1 / Alt+2 保存剪贴板图片；支持 PNG 和 Windows 位图，无需先粘贴。剪贴板同时含图片与文字时优先保存图片；若需记录文字，先复制文字以替换剪贴板图片。图片采集只读剪贴板，不发送 Ctrl+C，不主动截图或弹出窗口。点击总览中的图片可在新标签页查看原图。
